# Next Play 0.2.0 · primera versión para Windows

Descarga **NextPlay-Setup-0.2.0-x64.exe**, ejecútalo y abre **Next Play** desde su acceso directo. Compatible con Windows 10/11 de 64 bits. No necesitas instalar Git, Node, Python ni Codex.

- Asistente para tu perfil de Steam, claves y conexiones opcionales.
- Inicio de sesión oficial de ChatGPT y algoritmo local disponible sin IA.
- HowLongToBeat incluido para consultar duraciones.
- Icono de bandeja para abrir y cerrar la aplicación. Inicio con Windows opcional.
- Importación de una instalación anterior conservando los originales.
- Actualizaciones con comprobación SHA-256 y copia de seguridad previa.
- Acceso desde el móvil opcional en redes privadas; administración limitada al PC.

Tus datos se guardan en `%LOCALAPPDATA%\NextPlay` y se conservan al desinstalar. Si ya usabas la versión de desarrollo, ciérrala e impórtala antes de configurar la nueva instalación. Conecta ChatGPT de nuevo en el asistente.

**Distribución piloto sin firma de código:** Windows puede mostrar avisos de editor desconocido o bloquear la ejecución. Descarga únicamente desde este repositorio. Si tu equipo impide ejecutar aplicaciones sin firmar, esta versión piloto no será utilizable en él.

El repositorio de desarrollo es privado. El instalador contiene componentes y código ejecutable que pueden inspeccionarse. `SHA256SUMS.txt` comprueba la integridad de la descarga; no sustituye una firma de código.
